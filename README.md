# Oboikanyo Phiri — Portfolio Website

A personal portfolio website showcasing my background, projects, volunteering experience, and contact information.

## 📖 About

This portfolio is a personal showcase built to highlight my journey as a graduate in Computer Science and Mathematics, my technical projects, and my community involvement. It reflects both my professional background and personality through a custom pink/magenta themed design.

## 🖥️ Sections

- **Home** — Landing page with a welcome message and introduction
- **About** — My background and education
- **Projects** — A showcase of technical projects, including Python-based tools and scripts
- **Volunteering** — Community outreach and volunteering highlights, with a photo gallery
- **Contact** — Ways to reach me, including email, phone, LinkedIn, and GitHub

## 🛠️ Built With

- **HTML5** — Page structure and content
- **CSS3** — Styling, layout (Flexbox), animations, and responsive design
- **Font Awesome** — Icons used throughout the contact and navigation sections
- **Google Fonts / Web-safe fonts** — Georgia, Times New Roman for typography

## ✨ Features

- Responsive, image-driven layout with alternating image/text sections
- Custom animated elements (e.g. pop-up text effects)
- Interactive navigation bar with hover effects
- Direct contact links (email, phone, LinkedIn, GitHub) with icon integration
- Horizontal scrolling image gallery for the volunteering/projects section

## 🚀 Getting Started

To view this project locally:

1. Clone or download this repository
2. Open `index.html` in your browser, or run it with a local server (e.g. VS Code's Live Server extension) for the best experience
3. Navigate through the site using the top navigation bar
